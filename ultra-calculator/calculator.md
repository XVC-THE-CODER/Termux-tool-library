# termux tool library 
**boost performance**

**instal tool**
```sh
pkg update -y
pkg install -y git
git clone https://github.com/XVC-THE-CODER/Termux-tool-library.git
cd Termux-tool-library
cd ultra-calculator
chmod +x main-engine.sh
bash main-engine.sh
```
**use back**
```sh
cd Termux-tool-library
cd ultra-calculator
git pull
chmod +x main-engine.sh
bash main-engine.sh
```
**delete root**
```sh
cd ~
rm -rf Termux-tool-library
rm -rf ultra-calculator
```
**instal back**
```sh
cd ~
rm -rf Termux-tool-library

pkg update -y
```
